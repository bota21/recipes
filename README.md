# Моя книга рецептов

Статический сайт на HTML, CSS и JavaScript. Подходит для публикации через GitHub Pages — сборка и сервер не нужны.

## Что внутри
- `index.html` — структура страницы, верхние вкладки и список рецептов.
- `style.css` — адаптивное оформление для компьютера, планшета и телефона.
- `script.js` — поиск, фильтрация по вкладкам и открытие рецепта.
- `images/` — папка для собственных изображений блюд.

## Как открыть локально
Откройте `index.html` в браузере. Для обычного просмотра не требуется установка программ.

## Как опубликовать на GitHub Pages
1. Создайте новый публичный репозиторий, например `my-recipes`.
2. Загрузите в корень репозитория файлы `index.html`, `style.css`, `script.js`, `README.md` и папку `images`.
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Через некоторое время GitHub покажет адрес опубликованного сайта в разделе Pages.

## Как добавить свои фотографии
Положите изображение в папку `images`, например `ciabatta.jpg`. В карточке и в рецепте путь уже указан как `images/ciabatta.jpg`. Для своих фото лучше использовать JPG или WebP шириной около 1000–1400 px. Если локального изображения нет, шаблон временно использует удалённое изображение как запасной вариант.

## Как добавить рецепт
1. Добавьте карточку в `index.html` по образцу существующих `.recipe-card`.
2. Добавьте объект с данными нового рецепта в объект `recipes` в `script.js`.
3. Для новой категории укажите `data-category` карточки и добавьте соответствующую вкладку и название категории в `script.js`.
4. Добавьте фотографию в `images` и укажите её путь в карточке и объекте рецепта.

## Примечание
Рецепты в шаблоне — стартовые варианты, их можно редактировать под свои продукты, духовку и любимые пропорции. Google Fonts и запасные изображения требуют подключения к интернету; сам сайт остаётся статическим.
