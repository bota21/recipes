## О проекте

«Моя книга рецептов» — это персональная цифровая кулинарная книга, в которой собраны любимые, проверенные и интересные рецепты для домашнего приготовления.

Это место, где хранятся кулинарные идеи, семейные блюда и новые гастрономические открытия. Книга создана для того, чтобы рецепты всегда были под рукой, а процесс приготовления приносил удовольствие.

## Возможности

- 🔎 **Поиск рецептов** — быстрый поиск блюд по названию.
- 🥐 **Категории** — удобная сортировка рецептов по типам блюд.
- 🍽️ **Карточки рецептов** — фотографии, названия и время приготовления.
- 📖 **Подробные рецепты** — возможность открыть выбранное блюдо и посмотреть инструкцию приготовления.
- 🏡 **Домашняя коллекция** — личная подборка рецептов, которую можно постепенно расширять.

## Категории рецептов

- Выпечка
- Гарниры
- Напитки
- Другие домашние блюда

## Концепция

Главная идея проекта — создать собственную кулинарную библиотеку, которая объединяет практичность, простоту и уют.

Здесь нет случайных рецептов — только блюда, которые хочется сохранить, приготовить снова и поделиться ими с близкими.

Создано с любовью к кулинарии и домашнему уюту. ❤️
